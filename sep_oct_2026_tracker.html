Rules for the two months

1. Code everything. Don't passively watch the Java implementation. Recreate it in Python yourself.
2. Don't translate line-for-line blindly. Learn the Pythonic equivalent where appropriate: list, dict, set, deque, heapq, etc.
3. Don't chase the timestamp. The timestamp is a guide, not a deadline. Understanding beats completion speed.
4. Use the extra hours deliberately. Once the course is finished, use the remaining commitment for independent problems and reimplementation from memory.
5. Difficult topics get extra time. Trees, Graphs and Dynamic Programming deserve slower code-along sessions.
